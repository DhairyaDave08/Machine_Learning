# 🧠 Machine Learning

A curated collection of my Machine Learning implementations, notes, and experiments created while completing the **Machine Learning Specialization by Andrew Ng**. This repository serves as both my learning journal and a quick reference for fundamental ML concepts.

The notebooks focus on understanding the intuition behind each algorithm, implementing them in Python, visualizing results, and applying them to real datasets.
